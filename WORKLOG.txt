3. "SCAN OF THE WEEK" STILL VISIBLE IN THE LOCAL PREVIEW? -> localhost.bat REPLACED
   - Checked: every page of this version says "Scan of the month" / "Mẫu quét của tháng";
     the old address scan-of-the-week.html forwards to scan-of-the-month.html.
   - Probable cause of seeing "week": the old localhost.bat always used port 8001. If a
     preview window of an older version is still open, that old server keeps answering
     on 8001 and the browser shows the OLD site (and may also cache old files).
   - New localhost.bat: always serves its own folder, picks the first FREE port
     (8000, 8001, ...), shows folder + address in the window title, opens the browser.
   - Before testing: close all black "python -m http.server" windows, start localhost.bat
     from THIS folder, then press CTRL+F5.
   - Note: the live site (GitHub) keeps showing "week" until this version is published.
